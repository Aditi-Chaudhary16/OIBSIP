# Retail Sales Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python.

The analysis focuses on understanding sales performance, customer demographics, sales trends, and product category performance.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset

The dataset contains retail sales information including:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis Performed

The following analysis was performed:

1. Dataset structure and shape
2. Column names and data types
3. Missing value analysis
4. Descriptive statistics
5. Mean, median and mode analysis
6. Sales trend over time
7. Customer distribution by gender
8. Customer age distribution
9. Sales by product category
10. Correlation analysis
11. Sales by gender
12. Final sales and customer insights

## Key Findings

- Average sales amount is **456.0**.
- Maximum sale amount is **2000**.
- Minimum sale amount is **25**.
- There are **510 female** customers and **490 male** customers.
- Average customer age is approximately **41.39 years**.
- Customer ages range from **18 to 64 years**.
- **Electronics** is the highest-selling category with total sales of **156,905**.
- **Beauty** is the lowest-selling category with total sales of **143,515**.

## Visualizations

The project includes the following visualizations:

- Sales Trend Over Time
- Customer Distribution by Gender
- Customer Age Distribution
- Sales by Product Category
- Correlation Heatmap
- Sales by Gender

## Conclusion

The analysis provides useful insights into sales performance, customer demographics, and product category performance.

Electronics generated the highest sales among the product categories, while Beauty generated the lowest. Female customers were slightly higher in number than male customers. The average customer age was approximately 41 years.

The correlation analysis also helps understand relationships between numerical variables such as Price per Unit and Total Amount.

Overall, the analysis helps identify customer patterns, sales trends, and category-wise performance that can support better business decisions.
